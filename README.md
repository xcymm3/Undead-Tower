# Undead Tower

固定哨位、有限视角的原创低多边形第一人称射击游戏。当前版本 **0.3.0 / 护甲僵尸**，场景为灰松哨站北侧检查站。

## 启动

需要 Node.js 22.12+（本机使用 22.23.1）、npm，以及开启硬件加速并支持 WebGL 2 的桌面浏览器。

```powershell
cd D:\mydoc\React\undead-tower
npm ci
npm run dev
```

打开 <http://127.0.0.1:5175>，选择练习模式或正式模式后开始。安装过依赖后只需 `npm run dev`。也可以双击项目根目录的 `start-game.cmd`；启动器会打开浏览器并在当前控制台运行本地服务，关闭控制台即停止服务。

所有场景模型、材质和枪声均在本地程序生成；字体随构建打包，游戏运行不依赖外部图片、模型或音频服务。

## 两种模式

**练习模式**：四只僵尸静止站位，身体两发或头部一发击倒，3 秒后复位。不会失败，不记录排行榜。

**正式模式**：选择简单、普通或困难。僵尸从前方防区的 **8 个区域**持续出现：远端公路、公路左右两侧、检查站通道、检查站前空地、围栏通路、左右林地。每轮打乱区域顺序并依次使用，出生位置有小范围随机变化，随后沿各自的接近路线逼近哨塔。任意活僵尸进入玩家地面位置的 **8 米半径**，立即失败。刷新频率和移动速度随有效游玩时间增加，刷新频率最多 **每秒 10 只**。

各入口位于固定朝向的前方防区；窄窗口会跳过无法看见的固定入口，保留可见的正面入口和随窗口适配的两侧入口。

三档统一使用相同曲线：初始刷新 **0.65 只/秒**、初始移速 **1.25 米/秒**，每秒分别增加 **0.035 只/秒**和 **0.011 米/秒**。难度通过不同的僵尸组合区分。

| 难度 | 僵尸组合 |
| --- | --- |
| 简单 | 始终只有普通僵尸 |
| 普通 | 30 秒前只有普通；之后按 4 只普通、1 只路障循环 |
| 困难 | 同样在 30 秒后加入路障，每累计 4 只路障再追加 1 只铁桶 |

普通、路障、铁桶的生命分别为 **100 / 200 / 400**，爆头分别需要 **1 / 2 / 4 枪**，身体分别需要 **2 / 4 / 8 枪**。路障戴橙色路锥，铁桶戴灰色金属桶；击中护具也算头部伤害。30 秒后开始计数特殊序列，第一只路障约在 32.73 秒、第一只铁桶约在 40.98 秒出现。

在有效游玩 `t` 秒时，刷新率为 `min(10, 0.65 + 0.035 × t)`，移速为 `1.25 + 0.011 × t`。暂停、设置菜单、失焦和后台时间不计入坚守时长。正式模式的僵尸被击杀后不会复活，尸体会回收。

当前一般、熟练操作假设的模拟结果约在 1～3 分钟内，简单难度高手可能更久；没有强制 180 秒结束。假设、720 局原始结果和限制详见 [单局时长评估](docs/BALANCE.md)。

两种模式击杀僵尸都会在实际命中点喷溅红色方块血滴，爆头时喷溅更强。血滴扩散、下落并在约 1 秒内消散；重开和返回菜单会立即清空。

结束页面显示坚守时长、击杀数、发射数、命中率，支持同难度重试或返回主菜单。排行榜按三个难度分开保存，各保留前 10 名，按坚守时间降序，同时间比较击杀数。成绩自动保存到**当前浏览器的本地存储**，重新打开仍可查看；它不是联网榜，清除网站数据会移除成绩。浏览器禁止保存时，结果页会说明仅在当前页面保留。

0.3.0 护甲规则使用独立排行榜；旧版速度难度纪录保留在原存储项中，不混入当前榜单。

## 操作

| 操作 | 功能 |
| --- | --- |
| 移动鼠标 | 准星自由瞄准；枪口对准准星对应的世界位置 |
| 左键 / 按住左键 | 单发 / 自动连续射击 |
| R | 更换 30 发弹匣，哨站备弹不限 |
| Esc | 暂停 / 继续 |
| M | 开关声音 |
| 右上角设置 | 调整镜头阻尼、声音、粗颗粒像素效果 |
| 右上角全屏 | 进入 / 退出全屏 |

鼠标移出场景、松开左键、窗口失焦时会停止连射。窗口失焦或标签页隐藏时自动暂停。

## 有限视角的具体规则

- 玩家位置固定，始终面向北侧公路，不能移动、转身或绕视场一周。
- 鼠标使用画布内的**绝对位置**，不累积 `movementX / movementY`，也不锁定鼠标。
- 镜头在基准朝向周围最多水平 **±4°**、垂直 **±2.5°**，默认指数阻尼系数 2.4，接近目标角度 90% 约需 0.96 秒。
- 枪口瞄准不等待镜头缓动。先沿准星求世界目标点，再从枪械位置计算朝向；实际弹道从枪口出发，并再次检测遮挡。
- 后坐力采用枪身平移，重新求枪口朝向；镜头不额外随机震动，不会超出视角边界。

参数集中在 `src/game/config.ts`，算法在 `src/game/aim.ts`。

## 构建与验证

```powershell
npm run test       # 瞄准、武器、僵尸、刷新曲线、排行榜单元测试
npm run build      # TypeScript 检查和生产构建
npm run test:e2e   # Chrome 单浏览器、单 worker 交互验收
npm run balance    # 720 局纯逻辑时长模拟，写入 docs/balance-results.json
npm run preview   # 在 4175 端口预览 dist
```

`npm run verify` 顺序执行单元测试、构建、浏览器测试。端到端测试默认使用本机 Chrome；没有 Chrome 时需安装，或将 `playwright.config.ts` 的 channel 改为已安装的浏览器。

## 渲染预算

实际游玩最多绘制 60 FPS，默认渲染分辨率最高 1920×1080，阴影 1024×1024、每秒最多刷新约 10 次。标题、暂停和结算画面只在内容变化时绘制；后台页面停止绘制。静态方块按材质实例化合批，树木和草也是实例化绘制；整群僵尸共用一份实例模型，同时最多 256 只（含待回收尸体，达到上限时跳过刷新）；普通瞬时特效上限 160 个，血滴单独使用一份实例模型，最多 384 滴循环复用。可在设置中打开粗颗粒像素进一步降低分辨率。

当前面向桌面鼠标和键盘；小屏界面可显示，但未实现移动端专用触控操作。正式模式为持续生存，没有固定波次或通关终点。当前不含塔防经济、对局中途存档、联网排行榜、联机或独立桌面安装包。
