# Undead Tower

固定哨位、有限视角的原创低多边形第一人称射击游戏。当前版本 **0.4.0 / 防线与战斗体验**，场景为灰松哨站北侧检查站。

## 启动

**Windows 便携版**：双击 `release/Undead-Tower-0.4.0-portable-x64.exe`，可离线运行，无需安装 Node.js 或启动服务器。排行榜保存在 EXE 旁的 `Undead Tower Data` 文件夹；换位置时一起拷贝。使用、重新打包与成品验证见 [便携版说明](docs/PORTABLE.md)。

0.4.0 EXE 已同步 2026-09-04 的直线追击、拥挤避让、固定困难、护甲脱落、失败与纪录反馈、音量与 BGM，以及 0.775 秒换弹和新持枪动作。后续日常修改仍不自动重新打包，需明确要求后才更新 EXE。当前源码/网页版已接入六款无手部的 Quaternius 动画枪械，0.4.0 EXE 仍是旧单枪与手部版本。

以下为源码开发方式：

需要 Node.js 22.12+（本机使用 22.23.1）、npm，以及开启硬件加速并支持 WebGL 2 的桌面浏览器。

```powershell
cd D:\mydoc\React\undead-tower
npm ci
npm run dev
```

打开 <http://127.0.0.1:5175>，选择练习模式或正式模式后开始。安装过依赖后只需 `npm run dev`。也可以双击项目根目录的 `start-game.cmd`；启动器会打开浏览器并在当前控制台运行本地服务，关闭控制台即停止服务。

场景、僵尸、音效与背景音乐由本地程序生成；六款枪械使用 Quaternius Animated Guns Pack（CC0），FBX 模型和字体随构建打包，运行时不依赖外部服务。模型出处与适配说明见 [枪械资源许可](public/models/weapons/README.md)。

## 两种模式

**练习模式**：四只僵尸静止站位，使用默认步枪时身体两发或头部一发击倒，3 秒后复位。不会失败，不记录排行榜。

**正式模式**：固定为困难难度。僵尸从前方防区的 **8 个区域**持续出现：远端公路、公路左右两侧、检查站通道、检查站前空地、围栏通路、左右林地。每轮打乱区域顺序并依次使用，出生位置有小范围随机变化，随后沿各自的接近路线逼近哨塔。任意活僵尸进入玩家地面位置的 **8 米半径**，立即失败。刷新频率和移动速度随有效游玩时间增加，刷新频率最多 **每秒 10 只**。

各入口位于固定朝向的前方防区；窄窗口会跳过无法看见的固定入口，保留可见的正面入口和随窗口适配的两侧入口。

僵尸出生后沿最短直线朝玩家位置逼近，不再经过中途路径点或选择随机突破目标。八个区域仍轮流刷新，各区域位置保持随机，两侧入口留在可瞄准的屏幕边缘内。只有与其他活僵尸距离小于 1.35 米时才轻微错开；横向速度不超过 0.32 米/秒，也不超过当前移速的 20%，总速度不变。离开拥挤范围立即恢复朝玩家直行，最后 2 米减弱避让；身体朝向始终与实际位移一致。任何实际移动线段首次触碰 8 米防线便立即失败。

沿用原困难难度的曲线：初始刷新 **0.65 只/秒**、初始移速 **1.25 米/秒**，每秒分别增加 **0.035 只/秒**和 **0.011 米/秒**。从开局每 3 只普通加入 1 只路障，每累计 2 只路障追加 1 只铁桶，即 6 普通、2 路障、1 铁桶循环。

普通、路障、铁桶的生命分别为 **100 / 200 / 400**，使用默认步枪爆头分别需要 **1 / 2 / 4 枪**，身体分别需要 **2 / 4 / 8 枪**。路障戴橙色路锥，铁桶戴灰色金属桶；击中护具也算头部伤害。特殊序列从开局开始计数，没有 30 秒门槛；路障为第 4 只敌人，约 5.38 秒出现，困难的铁桶为第 9 只，约 10.75 秒出现。

生命由 **100 本体血量 + 0 / 100 / 300 护甲血量**组成。伤害先扣护甲，超出的部分扣本体，总击杀枪数保持不变。路障受击发出短促闷响，铁桶发出金属敲击声；护甲耗尽时原护具飞起、旋转、落地并消失，该僵尸立刻变为普通僵尸，原护具也不再挡子弹。击落护甲本身不计击杀。

正式模式地面显示与实际 8 米判定一致的金色圆弧和外侧刻度，作为可穿过哨塔前景显示的防线提示；僵尸接近时变橙，失败时变红。失败后定格约 2.4 秒，用红框和标签标出实际最先越线的僵尸，再显示结算；可提前查看结算，或从结算页再次查看突破位置。定格不会改变成绩或继续推进战斗。

在有效游玩 `t` 秒时，刷新率为 `min(10, 0.65 + 0.035 × t)`，移速为 `1.25 + 0.011 × t`。暂停、设置菜单、失焦和后台时间不计入坚守时长。正式模式的僵尸被击杀后不会复活，尸体会回收。

此前困难难度的一般、熟练操作假设的模拟结果约在 1～3 分钟内；没有强制 180 秒结束。假设、720 局历史结果和限制详见 [单局时长评估](docs/BALANCE.md)。该模拟不评估此次镜头跟随加快对真人瞄准的影响。

两种模式击杀僵尸都会在实际命中点喷溅红色方块血滴，爆头时喷溅更强。血滴扩散、下落并在约 1 秒内消散；重开和返回菜单会立即清空。

结束页面显示坚守时长、击杀数、发射数、命中率，支持重试或返回主菜单。排行榜只展示困难难度前 10 名，沿用已有困难成绩；旧简单、普通纪录保留在存储中，不混入当前榜单。按坚守时间降序，同时间比较击杀数。成绩自动保存到**当前浏览器的本地存储**，重新打开仍可查看；它不是联网榜，清除网站数据会移除成绩。浏览器禁止保存时，结果页会说明仅在当前页面保留。

当前开局护甲比例使用独立排行榜 `armor-v3`；旧版速度规则和 30 秒护甲规则的纪录保留在原存储项中，不混入当前榜单。

结算在写入本次成绩前比较困难榜最佳，显示首次建立、刷新、追平个人纪录，或距离最佳还差多少秒；以界面显示的 0.1 秒精度比较。

## 操作

| 操作 | 功能 |
| --- | --- |
| 移动鼠标 | 准星自由瞄准；枪口对准准星对应的世界位置 |
| 左键 | 开火；步枪与 P90 支持按住连发，其余枪械每次点击一发 |
| R | 当前武器装填，哨站备弹不限；霰弹枪逐发装填 |
| 数字键 1～6 / 鼠标滚轮 | 切换武器；滚轮首尾循环，也可点击右下角武器槽 |
| Esc | 暂停 / 继续 |
| M | 开关声音 |
| 右上角设置 | 调整总音量、静音、粗颗粒像素效果 |
| 右上角全屏 | 进入 / 退出全屏 |

鼠标移出场景、松开左键、窗口失焦时会停止连射。窗口失焦或标签页隐藏时自动暂停。

六把枪均为无手部悬浮模型，使用各自原始骨骼动作。配置集中在 `src/game/weapons.ts`：

| 按键 | 枪械 | 身体 / 爆头伤害 | 射击间隔 | 弹容量 | 装填时长 | 射击方式 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 步枪 | 50 / 100 | 0.15 秒 | 30 | 0.775 秒 | 按住连发 |
| 2 | P90 冲锋枪 | 40 / 80 | 0.09 秒 | 50 | 0.90 秒 | 按住连发 |
| 3 | 半自动手枪 | 75 / 150 | 0.22 秒 | 12 | 0.85 秒 | 单次点击 |
| 4 | 左轮手枪 | 100 / 200 | 0.40 秒 | 6 | 1.20 秒 | 单次点击 |
| 5 | 泵动霰弹枪 | 每颗 32 / 64 | 0.64 秒 | 6 | 每发 0.40 秒 | 单次点击，7 颗散射弹丸 |
| 6 | 栓动狙击枪 | 200 / 400 | 0.80 秒 | 5 | 1.15 秒 | 单次点击 |

每把枪独立保存当前弹量，切枪不会补弹。切换时先收枪，在画面下方换成新模型，再拔枪，总时长 0.4 秒；开火、泵动、拉栓或装填尚未结束时先排队，连续切换以最后请求为准。装填及切换阶段不能开火；切枪释放连射，需要再次按下左键。霰弹枪每完成一轮装填才增加一发，空枪装满需 2.40 秒。暂停会冻结所有动作与等待状态，重开重置六把枪。

模型统一尺寸、枪口与朝向，动作片段首尾平滑回到待机姿态。手枪套筒、左轮弹巢与快速装填器、霰弹枪泵柄和狙击枪枪栓使用原资源动画；没有手或手臂。短枪稍微上移，长枪靠近右下方；小窗口收拢横向位置。待机时每把枪的枪口与准星目标共线，弹道由实际枪口检测遮挡。

2026-09-04 做过一轮轻量数值平衡：步枪间隔从 0.115 增至 0.15 秒，保留一枪爆头普通僵尸；P90 伤害从 35 增至 40，提升扫射容错；手枪伤害从 60 增至 75、间隔从 0.30 缩至 0.22 秒；左轮间隔从 0.48 缩至 0.40 秒、换弹从 1.45 缩至 1.20 秒。霰弹枪每颗伤害从 24 增至 32，散射参数从 0.045 收至 0.036，泵动和逐发装填加快；狙击枪伤害从 150 增至 200、间隔从 0.90 缩至 0.80 秒，能一枪爆头击杀铁桶。对应射击动作时长同步调整，不能在泵动/拉栓结束前再次开火。

霰弹枪整发全部打身体的理论上限为 224，全部爆头为 448，实际取决于命中颗数和部位。本轮没有做真人对局校准，旧的单局时长模拟只适用于原单枪条件，不代表新武器系统的坚守时长。排行榜沿用当前本机困难榜，旧成绩保留；霰弹枪命中率按每次扣动扳机是否命中统计，不按弹丸累计，避免超过 100%。

总音量 0～100%，作用于音效与背景音乐。静音与音量独立，取消静音恢复原音量；两者自动保存在本机，刷新或重开仍保留。存储不可用时仍可在当前会话调节。

当前声音包括枪声、身体/头部命中提示、换弹开始/完成、失败提示、路障塑料撞击与脱落、铁桶金属敲击与脱落，以及僵尸死亡短低吼。护具声比枪声起音晚约 35 毫秒，方便分辨。死亡低吼有三种细微变化，只在确认击杀时触发，最多同时保留最新三声。

练习和正式游玩时播放原创 9.6 秒简短循环 BGM，轻旋律配低音和弦。音乐使用独立的低增益通路（0.028），战斗音效触发时进一步压至 0.007，再平滑恢复；总音量仍统一控制。暂停、设置、失焦/后台、失败或返回菜单时停止音乐，恢复游玩接续播放，重新开始从头播放；不会叠加多个循环。音乐和死亡音效的 PCM 缓存复用，不逐帧生成。

## 有限视角的具体规则

- 玩家位置固定，始终面向北侧公路，不能移动、转身或绕视场一周。
- 鼠标使用画布内的**绝对位置**，不累积 `movementX / movementY`，也不锁定鼠标。
- 镜头在基准朝向周围最多水平 **±4°**、垂直 **±2.5°**，固定指数阻尼系数 **5**（原调节范围中的最快跟随），接近目标角度 90% 约需 **0.46 秒**，设置中不再提供调节。
- 枪口瞄准不等待镜头缓动。先沿准星求世界目标点，再从枪械位置计算朝向；实际弹道从枪口出发，并再次检测遮挡。
- 后坐力采用枪身平移，重新求枪口朝向；镜头不额外随机震动，不会超出视角边界。

参数集中在 `src/game/config.ts`，算法在 `src/game/aim.ts`。

## 渲染预算

实际游玩最多绘制 60 FPS，默认渲染分辨率最高 1920×1080，阴影 1024×1024、每秒最多刷新约 10 次。标题、暂停和结算画面只在内容变化时绘制；后台页面停止绘制。静态方块按材质实例化合批，树木和草也是实例化绘制；整群僵尸共用一份实例模型，同时最多 256 只（含待回收尸体，达到上限时跳过刷新）；普通瞬时特效上限 160 个，血滴单独使用一份实例模型，最多 384 滴循环复用。可在设置中打开粗颗粒像素进一步降低分辨率。

当前面向桌面鼠标和键盘，提供网页版及 Windows x64 便携 EXE；小屏界面可显示，但未实现移动端专用触控操作。正式模式为持续生存，没有固定波次或通关终点。当前不含塔防经济、对局中途存档、联网排行榜或联机。
