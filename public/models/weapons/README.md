Retrieved 2026-09-04. Included original FBX files: Rifle, P90, Pistol,
Revolver, Shotgun, SniperRifle. Six files total 775,176 bytes.

Runtime adaptations in `src/game/weapon.ts`: local material palette, common
scale and muzzle alignment, pistol axis correction, unique revolver mesh
name to avoid the Bullets bone collision, bone animation filtering, and
blending clip endpoints back to a common resting pose. No hand meshes or
external textures are required. Models are served locally with the game.
